# devantler-tech Homebrew tap

Install released devantler-tech tools through [Homebrew](https://brew.sh).
This tap distributes **Casks**: prebuilt binaries and apps, not source-built formulas.
It does not create Kubernetes clusters or deploy the game when you add the tap.

| Cask | What you get | Platforms declared by the Cask |
| ---- | ----------- | ------------------------------ |
| [ksail](https://github.com/devantler-tech/ksail) | Kubernetes cluster/workload command-line tool | macOS Apple Silicon; Linux arm64 and amd64 |
| [ksail-desktop](https://github.com/devantler-tech/ksail) | Native KSail desktop app | macOS Apple Silicon |
| [world-at-ruin](https://github.com/devantler-tech/world-at-ruin) | World at Ruin desktop game | macOS Apple Silicon and Intel, universal app |

Start with an installed Homebrew on a compatible system. The two app Casks declare
macOS 11 as their app minimum, but Homebrew has its own, newer
[supported-system requirements](https://docs.brew.sh/Installation). This is not
a promise that Homebrew supports every older system the app can run on.
The KSail macOS Casks require Apple Silicon; they do not supply an Intel build.

## Inspect a package first

The first command downloads and registers this public tap in your local Homebrew
installation. Read the [Cask definition](Casks/ksail.rb) before the trust step:
it records trust for this specific Cask, permitting its Ruby code to run with
your user privileges. It does not trust the whole tap. The final command shows
package metadata without installing KSail:

```sh
brew tap devantler-tech/tap
brew trust --cask devantler-tech/tap/ksail
brew info --cask devantler-tech/tap/ksail
```

Success shows the KSail version, homepage and binary artifact. No GitHub login,
cloud credentials or Docker engine is needed for this inspection. Package
information is not proof that an installation or a cluster operation succeeded.
See Homebrew's [tap-trust guide](https://docs.brew.sh/Tap-Trust) for managing or
revoking that recorded trust.

## Install the tool you want

These commands download release artifacts and change your local installation.
Run only the one for the product you intend to install, on a supported platform:

Before installing, inspect the [Cask definitions](Casks/) and each product's release.
On macOS these Casks remove `com.apple.quarantine` after installation, bypassing the
normal quarantine-triggered Gatekeeper assessment. Consider that side effect and
Homebrew's [security model](https://docs.brew.sh/Homebrew-Security-and-Supply-Chain#casks-have-a-different-trust-model)
before trusting or installing a package.

```sh
brew install --cask devantler-tech/tap/ksail
brew install --cask devantler-tech/tap/ksail-desktop
brew install --cask devantler-tech/tap/world-at-ruin
```

For the CLI, `ksail --help` is a useful installation check that does not create a
cluster. Open the desktop apps from Applications. Follow each product's linked
guide for its runtime dependencies and next steps; installing a package does
not prove its backend or every feature is available.

To refresh an existing tap, `brew update` updates your Homebrew/tap metadata;
`brew upgrade --cask devantler-tech/tap/ksail` upgrades that installed product.
These are intentional local changes, not documentation validation commands.

## Documentation

Use `brew help`, `man brew` or [Homebrew's documentation](https://docs.brew.sh)
for package-manager behavior. Report a packaging problem in this tap's
[issues](https://github.com/devantler-tech/homebrew-tap/issues); a product bug
belongs in that product's repository. Sensitive reports use the private route
in [CONTRIBUTING.md](CONTRIBUTING.md).

## Maintenance

To improve the tap, start with [CONTRIBUTING.md](CONTRIBUTING.md).
Casks are generated by the products' release pipelines: do not hand-edit versions,
URLs or checksums. Repository conventions and release-gate details live in
[AGENTS.md](AGENTS.md). The tap is [Apache-2.0 licensed](LICENSE); installed
products have their own licenses.
